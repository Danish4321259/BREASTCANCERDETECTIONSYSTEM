Important Medical & Academic Disclaimer

This software is an educational prototype engineered as part of an MCA Artificial Intelligence and Machine Learning curriculum. It operates strictly on retrospective data from the Wisconsin Diagnostic Breast Cancer (WDBC) dataset. It has not undergone clinical trials, FDA review, or in-vitro validation. The output must never be used as a substitute for professional medical consultation, imaging, or histological biopsy.

Dataset Information

Wisconsin Diagnostic Breast Cancer (WDBC)

The system is trained and cross-validated on the classic Wisconsin Breast Cancer dataset collected by Dr. William H. Wolberg, W. Nick Street, and Olvi L. Mangasarian from the University of Wisconsin Hospitals.

  • Total Clinical Records 569 Cases
  • Malignant Tumors (Cancerous) 212 Cases (37.3%)
  • Benign Tumors (Non-Cancerous) 357 Cases (62.7%)
  • Cytological Nuclear Features 30 Dimensions
Learn More About Features & Architecture
10 Core Morphological Nuclear Traits 3 Aggregations each
Radius: Mean of distances from center to perimeter
Texture: Std deviation of gray-scale values
Perimeter: Nuclear boundary contour length
Area: 2D cross-sectional nuclear pixel area
Smoothness: Local variation in radius lengths
Compactness: perimeter² / area - 1.0
Concavity: Severity of concave contour regions
Concave Points: Count of concave contours
Symmetry: Nuclear bilateral symmetry
Fractal Dimension: "Coastline" approximation - 1
Each characteristic is evaluated across Mean, Standard Error (SE), and Worst / Largest values (10 × 3 = 30 input features).

Comparative Modeling Framework

Evaluating Classical Supervised ML vs. Deep Feedforward Neural Networks

Classical Machine Learning
Scikit-Learn Supervised Algorithms

Rigorous cross-validation across 6 benchmark algorithms with stratified sampling to preserve class ratios:

Support Vector Machine (RBF) Logistic Regression (L2) Random Forest (150 trees) Gradient Boosting K-Nearest Neighbors Decision Tree

Key Benefit: Rapid inference (<0.05ms), high explainability, and proven performance on small-to-medium biomedical tabular datasets.

Deep Learning (ANN)
TensorFlow / Keras Sequential Model

Multi-layer Artificial Neural Network with dropout regularization and early stopping:

  • Input Layer: 30 normalized cytological features
  • Dense Hidden 1: 64 units + ReLU + Dropout (0.3)
  • Dense Hidden 2: 32 units + ReLU + Dropout (0.2)
  • Output Layer: 1 unit + Sigmoid activation (calibrated P(Malignancy))
  • Optimizer & Loss: Adam (lr=0.001) with Binary Cross-Entropy

Key Benefit: Captures high-order non-linear feature interactions with built-in dropout to avoid overfitting.
